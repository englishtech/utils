[**async_wikipedia_pagedata_parser.py**](async_wikipedia_pagedata_parser.py)
 
Асинхронный парсер русской Википедии: по списку URL вытягивает из инфобоксов страниц даты рождения/смерти, продолжительность жизни (в днях), имя и профессию и складывает всё в БД SQLite.
Читает plaintext-файл со ссылками (по 1 в строке) (имя файла вводится в терминале).
Работает асинхронно, может парсить файл с ~100000 ссылок (протестировано). Но оптимально разбивать tasks на чанки по ~50-80 ссылок - при большем числе одновременных запросов Википедия может отключить соединение.

- За ~4-5 сек. обрабатывает пачку (≈15× быстрее синхронного цикла) 

- Результат – БД `my_database.db`. Никаких внешних модулей кроме `aiohttp, bs4, requests`

[**async_wikipedia_search_parser.py**](async_wikipedia_search_parser.py)

Универсальный асинхронный парсер русской Википедии. Подходит для быстрого сбора базы вики-статей под любую тематику — от персоналий до технических терминов.
По любому запросу в терминале скрипт сам пролистает всю поисковую выдачу на странице поиска (https://ru.wikipedia.org/w/index.php?search=&title=...)
*В Википедии есть ограничение выдачи результатов до 10000 элементов.

- Настраивается пагинация, если результаты поиска не помещаются на одну страницу (макс. 5000 элементов/стр.)

- Сохраняет ссылки построчно в текстовый файл, название - "транслитерированный_запрос.txt"

- Работает без API (только aiohttp, bs4, requests), устойчив к ошибкам, показывает прогресс и время выполнения.

[**gorzdrav_parsing.py**](gorzdrav_parsing.py)

Эта утилита на Python использует библиотеку `Selenium` с браузером (через `webdriver-manager`) для автоматизированного перехода на страницы расписаний медицинских учреждений на сайте `gorzdrav.spb.ru`, извлечения информации о районе, организации и специальности, подсчёта количества доступных врачей и доступных «номерков» (при свободной записи) у каждого врача, а затем выводит результаты в консоль. Возвращает словарь с ключами `med_info`, `doctors_qty` и `doctors_info` (список словарей с именами врачей и их доступными номерками). Спроектирована как часть более крупного проекта – Telegram‑бота для автоматического отслеживания появления свободных номерков и оповещения пользователей.

[**comprim.py**](comprim.py)

Утилита на базе библиотеки `pillow` пакетно сжимает все найденные JPG/JPEG-изображения в указанной папке до заданного размера файла. 
Поддерживает настройку через аргументы командной строки: целевой размер, минимальное качество, префикс выходных файлов. 
Сохраняет EXIF-данные и временные метки исходных файлов, применяет сглаживание при сильном сжатии.
Оптимальное качество под нужный размер подбирается методом бинарного поиска.
Сжатые файлы сохраняются в той же папке с указанным префиксом.

[**sqlite_to_ydb.py**](sqlite_to_ydb.py)

Утилита предназначена для быстрой миграции данных из локальной базы SQLite в облачную YDB. Скрипт выгружает все записи из указанной таблицы, автоматически приводит типы данных и пакетно загружает их в целевую таблицу YDB через асинхронный драйвер. В процессе переноса для каждой записи автоматически формируется актуальная метка времени обновления, что позволяет легко синхронизировать локальные архивы с облачным хранилищем без ручного преобразования схем.
